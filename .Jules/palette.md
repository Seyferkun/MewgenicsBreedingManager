## 2024-06-25 - Use Native Clear Buttons on PySide6 QLineEdits
**Learning:** PySide6 provides a native clear button functionality for QLineEdit widgets using `setClearButtonEnabled(True)`. This is especially useful for search and filter inputs to improve usability without needing to build a custom button or layout.
**Action:** Always enable `setClearButtonEnabled(True)` on QLineEdit widgets used as search or filter inputs across the UI to ensure a consistent and accessible experience for users clearing their search query.
