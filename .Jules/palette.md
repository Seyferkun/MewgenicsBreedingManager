## 2025-05-15 - Search Input Usability
**Learning:** For consistent PySide6 UX in the Python application, enable `setClearButtonEnabled(True)` on `QLineEdit` widgets used as search or filter inputs to provide a native clear button, and ensure a helpful placeholder text is set.
**Action:** Always enable `setClearButtonEnabled(True)` on QLineEdit fields that are meant to filter or search data.
