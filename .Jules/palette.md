## $(date +%Y-%m-%d) - PySide6 Text Input Clear Buttons
**Learning:** PySide6 provides a built-in method `setClearButtonEnabled(True)` for `QLineEdit` widgets, which is a native and simple way to provide users an instant "clear" action for filter/search inputs without writing custom UI buttons.
**Action:** Always enable the clear button on `QLineEdit` fields used for filtering and searching.
