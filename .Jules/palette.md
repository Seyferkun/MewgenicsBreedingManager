## 2024-05-24 - PySide6 QLineEdit Native Clear Buttons
**Learning:** PySide6 provides a built-in native clear button functionality for QLineEdit widgets, which improves accessibility and UX, especially for search and filter inputs. This provides users an easy way to clear inputs without relying entirely on keyboard strokes or manually selecting text to delete.
**Action:** Consistently enable `setClearButtonEnabled(True)` on `QLineEdit` widgets that are used as search or filter inputs.
