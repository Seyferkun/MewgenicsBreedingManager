## 2026-05-29 - Native clear buttons for PySide6 filter inputs
**Learning:** For consistent and accessible PySide6 UX, 'setClearButtonEnabled(True)' should be applied to 'QLineEdit' widgets used as search or filter inputs. It provides a native, keyboard-accessible clear button.
**Action:** Always enable this property when adding or modifying search/filter inputs to ensure a polished and accessible user experience.
