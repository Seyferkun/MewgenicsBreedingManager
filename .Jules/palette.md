## 2024-05-26 - Native Clear Buttons in QLineEdit
**Learning:** PySide6 provides a native `.setClearButtonEnabled(True)` method for `QLineEdit` widgets, which is an excellent micro-UX improvement for search and filter fields. It avoids needing custom icon layouts.
**Action:** Always enable this for search/filter input fields across PyQt/PySide6 applications for immediate UX polish.
