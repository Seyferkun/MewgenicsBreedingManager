## 2024-05-24 - Consistent clear buttons on PySide6 QLineEdits\n**Learning:** QLineEdit widgets used as search or filter inputs lack a native way to quickly clear them, which hurts accessibility and UX, especially since this app relies heavily on searching and filtering lists of cats or items.\n**Action:** When adding QLineEdit elements for search or filter, always enable `setClearButtonEnabled(True)` and ensure a helpful placeholder text is set via `setPlaceholderText()`.
