## 2024-XX-XX - [Added native clear button to QLineEdits]
**Learning:** PySide6's QLineEdit has a native clear button (`setClearButtonEnabled(True)`) which is very useful for search and filter inputs, enhancing usability and accessibility compared to backspacing.
**Action:** Use `setClearButtonEnabled(True)` on all QLineEdit instances used for filtering or searching lists in PySide6 applications.
