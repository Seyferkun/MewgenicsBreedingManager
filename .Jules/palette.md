## 2024-06-11 - Add Native Clear Buttons to PySide6 Search Inputs\n**Learning:** Users can clear filter/search inputs significantly faster with a native clear button than repeatedly pressing Backspace or manually selecting all text to delete. In PySide6, this is supported natively without requiring custom icon widgets or complex styling.\n**Action:** Whenever a `QLineEdit` is used exclusively for searching or filtering lists/tables in PySide6 applications, enable `setClearButtonEnabled(True)` by default to improve usability.
