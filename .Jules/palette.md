## 2024-05-24 - PySide6 Native Search Clear Button
**Learning:** `QLineEdit` in PySide6/Qt supports a native, zero-friction clear button on search/filter inputs via `setClearButtonEnabled(True)`. This provides a consistent, accessible way to quickly clear input without needing custom overlay buttons or layout management.
**Action:** Use `setClearButtonEnabled(True)` natively on PySide6 `QLineEdit` instances whenever they are used for search, filtering, or temporary input to significantly enhance usability with a single line of code.
